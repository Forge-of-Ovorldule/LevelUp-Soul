## 📋 Project Description
**LevelUp-Soul** is more than just a tracker; it is a software suite that combines classical planning mechanisms with role-playing game (RPG) models. 

> [!IMPORTANT]
> **Key Difference:** Rejection of external triggers (notifications) in favor of building internal responsibility. We use high-precision algorithms to calculate the "Soul Level."

### ✨ Features:
- **🚀 Cross-platform:** Native UI on Android, Windows, Linux, MacOS, and Web (Wasm).
- **🧮 Mathematical Precision:** Utilization of `BigDecimal` to eliminate errors in progress calculations.
- **🛡 Privacy First:** 100% local data storage (JSON/XML). No clouds or third-party servers.
- **📊 Deep Analytics:** Activity heatmaps and interactive discipline charts.
