## 📋 Описание проекта
**LevelUp-Soul** — это не просто трекер, а программный комплекс, объединяющий механизмы классического планирования с ролевыми игровыми моделями (RPG). 

> [!IMPORTANT]
> **Ключевое отличие:** Отказ от внешних триггеров (уведомлений) в пользу формирования внутренней ответственности. Мы используем высокоточные алгоритмы для вычисления «Уровня Души».

### ✨ Особенности:
- **🚀 Кроссплатформенность:** Нативный UI на Android, Windows, Linux, MacOS и Web (Wasm).
- **🧮 Математическая точность:** Использование `BigDecimal` для исключения погрешностей при расчете прогресса.
- **🛡 Privacy First:** 100% локальное хранение данных (JSON/XML). Никаких облаков и сторонних серверов.
- **📊 Глубокая аналитика:** Тепловые карты активности и интерактивные графики дисциплины.
